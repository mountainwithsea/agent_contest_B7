# 输入文件到引用核验

1. 输入 PDF、DOCX、TXT 或参考文献截图。当前上传限制为 20 MB；扫描与图像转写按任务限制调用视觉模型。
2. 普通文字文档优先使用算法定位参考文献区域并分条；页面上以彩色框展示提取范围及各条引用，保留原文位置。
3. GROBID 与 AnyStyle 公共服务解析字段，本地检查题名、作者、编号与原文的对应。规范化姓/名顺序、首字母、复姓与文献类型标记；少量困难题名才进入模型兜底。
4. Crossref 第一层单独查询。原始 DOI/arXiv 编号与题名共同对应，或题名与全部明确作者对应，才形成身份锚点；充分则结束。否则按文献类型分层补查 Europe PMC、DataCite、arXiv、图书目录、OpenAlex 等。
5. 分别输出作品存在性、字段差异、来源执行状态。查询失败或未检出不能直接判为文献虚构；不验证论文正文某句话是否被文献内容支持。
6. 查询参数、原始响应、派生字段、模型记录与哈希证据保存在本机任务目录，可导出审计 ZIP。未确认条目可继续补查，复用已完成步骤并保留历史记录。

`reference-checker/ref_app` 为网页、任务与编排；`reference_extractor` 为读取、区域和分组；`reference_identity` 为候选、证据和身份判断；`b7_shared` 保留必需的配置及跨进程服务限流。

独立仓库保留原来验证过的算法，迁移只调整启动、配置和桌面包装。公共解析服务、网络覆盖和姓名歧义仍会导致合理的待核结果。
