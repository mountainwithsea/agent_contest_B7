使用步骤

  1. 在设置中填写自己的 API Key，测试连接并保存。
  2. 回到文献核验页上传文件。
  3. 查看结果，点击证据追溯原文，导出报告或审计包。

核验“待判定”不等于文献虚构；字段有差异也不等于作品不存在。

数据与隐私

任务与证据保存在本机。模型与在线解析服务会接收相应处理材料；请使用允许上传的文件。

升级安装保留任务与设置；个人密钥不会包含在导出的任务审计包中。
